# 모던하고 귀여운 웹 테마

## 2026-09-11 · 웹 테마 구현·로컬 검증 완료
사용자 확정: 실제 웹을 모던하고 귀엽게 개편하며 Figma는 앞으로 작업 흐름에서 제외한다. 이전 Figma 컴포넌트 통합·캡처 정리·요금제 확인 대기는 재개하지 않는다.
구현: 랜딩·Plan·Do·See·로그인·계획 작성에 SUIT 본문/SUITE 제목 자체 호스팅 글꼴과 OFL 라이선스, 민트·살구·라일락, 둥근 카드/컨트롤, 작은 새싹 브랜드 모양을 적용했다. 채택된 계획→할 일 계층과 낮은 행, 모바일 리스트, 인라인 추가, 직접 상태 변경과 서버 계약은 유지했다.
실제 검증: 타입 검사·기존 단위18개·Windows 배포용 빌드 통과. 6화면×1280/900/760/390/320px의30조건에서 가로 넘침 없음. 랜딩 키보드/예시 연결, 인라인 펼침·입력 보존·추가 설정3폭, 오늘 마감 URL/상세 필터, See 근거/시·분 표시, 터치 추가 버튼44px의7개 동작 통과. 배포용 빌드 브라우저 페이지/콘솔 오류0·외부 요청0·변경 요청0. 기본 글자/배경 대비11.00, 보조 글자4.76, 흰 버튼 글자6.02, 공개 안내5.12를 계산했다. 전체 접근성 인증을 뜻하지 않는다.
첫 검사에서 랜딩 배경 장식의9px 넘침을 발견해 회전을 제거했다. 개발 미리보기에서는 탭이 반응하지 않았으나 최종 배포용 빌드에서 정상 작동을 확인했다. 검사기의 상세 필터 라벨/URL 선택과 화면 갱신 대기는 실제 코드에 맞게 교정했다.
범위와 한계: 예시만 반환하는 별도 읽기 전용 로컬 API로 검사했으며 실제 DB 저장·서버 필터 계산의 재검증은 아니다. 이번 API/DB/인증 기능 소스 변경은 없고 계약은 design 상태를 유지한다. 운영 배포·원격 푸시는 이번 변경에서 하지 않았다. 소셜 보류·원문44/번호 없는18·실제 사용자1/5/3 및 최종 인수 미완료를 유지한다. 근거는 웹 docs/soft-modern-theme.md·soft-modern-theme-verification.json, 설계 docs/soft-modern-theme.md다.

## 구현 출처

중앙 RULES.md 전체·requirements.json 원문44개·번호 없는18조건, docs/pds-design.md의 채택된 첫 계층 설계/인라인 추가, 웹 AGENTS.md, Spring contracts/pds-schema-v2.json의 접근/관계 계약을 직접 확인했다. 도메인/API/인증 상태 로직을 수정하지 않고 표현만 바꿨다.

본문은 [SUIT](https://github.com/sun-typeface/SUIT), 제목은 [SUITE](https://github.com/sun-typeface/SUITE) Variable을 사용한다. 원본 WOFF2와 OFL 라이선스를 src/app/fonts에 포함했다. 글꼴은 자체 제공하며 기본 모션과 줄이기 설정을 유지한다.

웹 브랜치: codex/soft-modern-theme. 최종 입력 파일 SHA-256, 계약 SHA-256과 실제 검증 결과는 [웹 검증 JSON](../../PDC_Diary_Nextjs/docs/soft-modern-theme-verification.json)에 보관한다. 스크린샷은 로컬 .tmp/soft-theme에 있으며 허구의 예시 데이터다. 로컬 미리보기 http://127.0.0.1:4180/plans 는 모든 변경 요청을 거절한다.
