# Spring 보안 점검 안내

2026-09-09 사용자 확정: `PDC_Diary_Security`에 Spring·Next.js 등 항목별 보안점검과 설계를 기록한다. 이전 `docs/security/` 추천을 이 결정으로 대체한다.

정본: [Spring 보안 점검과 보호 설계](../../PDC_Diary_Security/spring/security-review.md) · [노션 보안 문서](https://app.notion.com/p/3d60def9f62681b9a208e7aa1067c14b).

Swagger의 현재 Caddy 정적 문서 경계에는 인증이 없으며, 전체 문서 경로를 보호하는 비밀번호 설계를 작성했다. 정적 소스 검토에서 자원 사용 한도와 reset/동시 로그인 경합 2건을 확인했고, 40개 보안 항목의 코드 근거·권고·미검증 사항을 분리했다. 실제 장애/우회 재현, 운영 설정 변경, 비밀번호 적용, DB 변경, 새 회귀 시험은 하지 않았다.

공개 과제의 무인증 기능·제출 조건과 원문44개·번호 없는 조건은 유지한다. T06-C01/C36/C57/C58/C82와 인증·개인 공간 경계의 검증은 기존 조건을 약화하지 않으며, 미검증 항목을 통과로 올리지 않는다. API/DB 계약은 이번에 변경하지 않았다.
